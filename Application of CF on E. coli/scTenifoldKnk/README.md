# Overview of scTenifoldKnk application 

1) To run scTenifoldKnk in R, use the "To_run_sctnKnk.R" file. The two files to run the code "ecoli_samples_kos_wts.csv" and "raw_GE_data.RData"[https://drive.google.com/drive/folders/1JklQyTEQaLXnTw1UYgwgfI8OTQ2mAun4] are provided.
2) Run the code for one gene KO at a time
3) The list of genes constituting  the "Biomass precursor" gene set is given in "biomass_precursor_genes.csv"
