# Overview of applying CF to *B. subtilis* 

1) Use the [CausalFlux.R](https://github.com/BIRDSgroup/CausalFlux/blob/main/Application%20of%20CF%20on%20E.%20coli/CausalFlux_Runs/CausalFlux.R) code that was used for running E. coli datasets, but with modifications to use *B. subtilis* datasets
2) Refer to [CF framework](https://github.com/BIRDSgroup/CausalFlux/tree/main/Our%20CF%20framework) for more details on other files/data required to run the code (.m files, etc)
3) Use the datasets provided for *B. subtilis*  
4) Check the Results folder to see the list of genes on which single-gene KO was performed
